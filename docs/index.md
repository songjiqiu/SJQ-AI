# PPT创造大师

PPT创造大师是一款面向中文用户优先设计的智能演示创作平台，目标是让用户通过输入想法生成结构清晰、设计专业的 PPT。

## 首版骨架

当前版本已经落地一个 Next.js 应用骨架。登录后的根路径会按角色分流：普通用户进入“创作工作台”，管理员进入“管理端”。创作工作台采用三步页面流程：先输入原始文本或创作想法、文本或 `.docx` 文档参考文件，并选择 PPT 类型和叙事风格；点击生成大纲草稿后先生成并确认输入分析，再生成大纲草稿。大纲确认页默认以卡片化只读视图展示封面、目录和页面内容，需要调整时点击“编辑大纲”进入完整编辑模式；最后基于已保存的大纲生成预览 PPT、Mock 图片图层、Web 动效、内容审核、一致性评分和 PPTX 下载文件。

应用已接入邮箱密码账号体系，工作台需要登录访问。登录后可在“体验设置”的“通用”页切换语言或退出登录，在“账号”页查看邮箱、维护名称、上传头像和登录密码。头像超过 1MB 时会在上传前压缩，并保存到 `storage/uploads/avatars` 目录。在“外观”页可切换浅色、深色、跟随系统和全应用配色预设。AI 供应商、LLM 模型、图片模型和向量模型按账号隔离管理，并在进入对应设置页签时按需加载；三类模型统一选择供应商、显示名称、模型 ID、默认温度、启用状态和默认状态。配置加载按接口独立容错，某个配置接口失败时不会清空已成功读取的列表。API Key 只在 AI 供应商中维护，使用服务端 AES-GCM 加密后存入 MySQL，界面只显示是否已配置密钥。

应用已提供管理员权限、管理端首页与独立用户管理页。通过 `APP_ADMIN_EMAILS` 指定的邮箱会在注册、登录或读取会话时同步为管理员，管理员可查看用户、切换角色、启用或禁用账号；禁用账号会立即清理该用户所有登录会话。管理员需要创作 PPT 时，可从管理端点击“创作工作台”进入创作页面。

生成链路由 Next.js API 统一承载。`POST /api/decks/outline/analyze` 负责第一轮输入分析并返回受众、目标、核心信息和推荐页数；用户确认后，`POST /api/decks/outline` 生成结构大纲、统一视觉说明和每页详细文案 JSON；`POST /api/decks/generate` 只接收 `outlineDraftId` 并创建或复用异步预览 PPT 生成任务，后台严格复用已保存大纲完成单页图层 JSON、图片素材缓存/生成、PPTX 合成和历史保存；`GET /api/decks/{id}/status` 提供生成进度，只有明确失败才显示失败，长时间任务会继续后台轮询；`GET /api/decks` 只返回已完成且具备 PPTX 产物的历史列表，`GET /api/decks/{id}` 提供账号隔离的详情；PPTX 与图层文件通过鉴权 API 读取。工作台侧栏、大纲详情页和预览详情页支持删除当前账号的大纲草稿或生成历史；删除生成历史会同步清理本地 PPTX 与图片图层产物，生成中的草稿或历史会阻止删除。

## 设计约定

- 默认语言为 `zh-CN`，可在登录后的“体验设置 > 通用”中切换 `en-US`。
- 用户可见文案统一维护在 `messages/`。
- 默认配色预设为“星图”，并预留矩阵、深空、晨雾；入口位于“体验设置 > 外观”，会作用于整个前端。
- 创作输入页使用双轴生成意图：`PPT 类型`决定场景结构，默认“商务汇报”；`叙事风格`决定表达方式，默认“战略叙事”；两组选项在桌面端使用一致的 4 列等宽网格，叙事风格保持两行显示；首屏标题区、左侧内容区和右侧栏采用收窄布局，重置和生成大纲草稿操作位于右侧栏下方并使用整行宽按钮。
- 大纲确认页默认展示只读卡片化大纲，保留封面、目录、章节和内容页的纵向结构；预览/编辑状态、页数和“编辑大纲”入口位于底部操作栏中间，用户可直接生成预览 PPT，也可点击“编辑大纲”后修改标题、摘要、页面文案和统一视觉说明。保存或生成会继续复用同一份大纲草稿。
- 右侧栏的大纲草稿和生成历史卡片提供删除图标；大纲详情页底部操作栏和 PPT 预览详情页顶部操作区也提供删除入口，删除前必须二次确认。
- PPT 类型和叙事风格在 AI 生成链路中只作为不可变引用值；每轮 LLM 输出都必须与用户原始选择保持一致，不能由模型改写、翻译或替换。
- 内置 PPT 类型按使用场景分组，包括商务办公、销售市场、教学培训、研究分析、运营活动和个人展示；叙事风格内置战略叙事、数据论证、故事叙事、问题方案、极简商务、教学讲解、视觉提案和复盘总结。
- 浅色、深色、跟随系统由本地主题 Provider 管理，入口位于“体验设置 > 外观”。
- 当前生成流程优先调用 OpenAI-compatible 文本模型；未配置 `OPENAI_API_KEY` 时使用本地模拟 fallback。
- 若当前账号配置了启用的默认 LLM 模型，AI 拆页优先使用账号配置；否则回退到 `.env` 中的 OpenAI-compatible 配置。
- AI JSON 生成会先使用结构化输出，再退回 JSON mode；若 DeepSeek 等兼容服务商暂不支持 `json_schema` 类型的 `response_format`，会在重试提示中附带 JSON Schema，并对大纲近似 JSON 做窄口径规范化，再交由 zod 严格校验。
- LLM、图片和向量模型拉取都会按常见模型品牌前缀过滤当前供应商返回结果，例如豆包只展示 `doubao-*`，避免同一兼容接口混入其他模型品牌。
- `/{locale}` 是角色分流入口，创作工作台路径为 `/{locale}/workbench`，管理端路径为 `/{locale}/admin`。
- 用户管理页路径为 `/{locale}/admin/users`，普通用户访问管理端路由会被重定向回创作工作台。
- 图片图层第一版使用可插拔 Mock SVG 生成器，后续可替换为真实图片生成服务；图片素材按账号内缓存复用，生成后写入 `storage/assets` 和项目资产目录；PPTX 第一版静态导出并写入 Web 动效备注/metadata，Web 预览支持动效播放。
