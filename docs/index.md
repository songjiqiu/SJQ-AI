# PPT创造大师

PPT创造大师是一款面向中文用户优先设计的智能演示创作平台，目标是让用户通过输入想法生成结构清晰、设计专业的 PPT。

## 首版骨架

当前版本已经落地一个 Next.js 应用骨架。登录后的根路径会按角色分流：普通用户进入“创作工作台”，管理员进入“管理端”。创作工作台采用三步页面流程：先输入原始文本或创作想法、文本或 `.docx` 文档参考文件，并选择 PPT 类型和可选页数；点击生成大纲草稿后先生成并确认输入分析，再生成大纲草稿。大纲确认页默认以卡片化只读视图展示封面、目录和页面内容，需要调整时点击“编辑大纲”进入完整编辑模式；最后基于已保存的大纲生成预览 PPT、Mock 图片图层、Web 动效、内容审核、一致性评分和 PPTX 下载文件。

应用已接入邮箱密码账号体系，工作台需要登录访问。登录后可在“体验设置”的“通用”页切换语言或退出登录，在“账号”页查看邮箱、维护名称、上传头像和登录密码。头像超过 1MB 时会在上传前压缩，并保存到 `storage/uploads/avatars` 目录。在“外观”页可切换浅色、深色、跟随系统和全应用配色预设。AI 供应商、LLM 模型、图片模型和向量模型按账号隔离管理，并在进入对应设置页签时按需加载；三类模型统一选择供应商、显示名称、模型 ID、默认温度、启用状态和默认状态。配置加载按接口独立容错，某个配置接口失败时不会清空已成功读取的列表。API Key 只在 AI 供应商中维护，使用服务端 AES-GCM 加密后存入 MySQL，界面只显示是否已配置密钥。

应用已提供管理员权限、管理端首页、独立用户管理页和模板工作区。通过 `APP_ADMIN_EMAILS` 指定的邮箱会在注册、登录或读取会话时同步为管理员，管理员可查看用户、切换角色、启用或禁用账号；禁用账号会立即清理该用户所有登录会话。管理员可进入“模板工作区”维护 PPT 模板库，模板按章节页、封面大标题、标题 + 正文/要点、大图背景、左右图文、图表、双栏对比、引用/金句页、时间轴、流程/步骤、关键指标页、四象限/矩阵、结束页等固定分类组织，每个模板保存完整页面 JSON 并支持可视化设计器编辑。管理员需要创作 PPT 时，可从管理端点击“创作工作台”进入创作页面。

生成链路由 Next.js API 统一承载。`POST /api/decks/outline/analyze` 负责第一轮输入分析并返回受众、目标、核心信息和推荐页数；用户确认后，`POST /api/decks/outline` 生成结构大纲、统一视觉说明和每页详细文案 JSON。每页详细大纲除原有标题、要点、演讲目标和视觉意图外，还结构化保存本页核心表达句、叙事作用、主/支撑/补充内容层级、页间衔接、讲解深度、来源要求、拆合规则、受众关注点、行动或认知目标和内容边界。统一视觉说明除原有风格、色板、排版、图片风格和一致性/禁用规则外，还结构化保存页面基础规格、字体层级规则、颜色角色和图片生成/使用规则：页面默认 16:9、13.333 x 7.5 inch、安全边距 `0.5`，并记录 12 栏栅格说明；`colorRoles` 直接保存背景、卡片/表面、标题、正文、强调、高亮、图表和装饰色角色，正文色与背景色对比度要求不低于 `4.5:1`；`typographyRules` 直接保存默认字号、最小字号、最大行数、行高、字体 fallback 和封面/页标题/正文/注释/图表标签字号等级；背景图需避开高对比文字区域，图片主体不能压在标题区。统一视觉说明还保存按当前 PPT 类型自动匹配的视觉基调、信息密度、间距留白、图表、图片/插画、图标、强调和视觉禁用规则；`pptTypeVisualTone` 只保存所选 PPT 类型、推荐视觉基调和视觉关键词，不保存完整类型对照表，工作台也只展示这一条匹配结果。当前映射覆盖现有 20 个可选 PPT 类型，商务办公、销售市场、教学培训、研究分析和个人展示仅作为分组原则，不作为新的类型选项。统一视觉说明的主题名称只描述内容或视觉主题，不绑定“星图”等外观配色预设；工作台会把色板以及规则文本中的 HEX 色值显示为颜色块和色码。`POST /api/decks/generate` 只接收 `outlineDraftId` 并创建或复用异步预览 PPT 生成任务，后台严格复用已保存大纲，并以固定 3 路并发生成单页语义编排、预览占位图和真实图片素材。单页 LLM 会先判断页面角色、表达目标、核心信息、观众记忆点和内容密度，再拆出三层内容层级；随后从 15 个内置 `layoutType` 中选出 2-3 个候选模板比较并保存 `layoutSelection`，同时输出 `constraints` 和语义元素。服务端随后按 `selectedLayoutType` 确定性排版成现有坐标元素、图片请求和页面 JSON，执行 schema 校验并生成逐页五维 `designQualityScore`；低于阈值的页面会进入一次 LLM 自动修复，失败时保留最佳版本并标记修复状态，保证 Web 预览与 PPTX 导出继续兼容。前 `min(5, 总页数)` 页会优先按页序写入默认占位图并开放轻量预览，剩余页面、真实图片生成、质量审核和最终 PPTX 合成继续在后台运行；最终合成前会重新按页序读取页面，确保 PPTX 页序稳定；`GET /api/decks/{id}/status` 提供 `previewReady` 与生成进度，只有明确失败才显示失败，长时间任务会继续后台轮询；`GET /api/decks` 只返回已完成且具备 PPTX 产物的历史列表，`GET /api/decks/{id}` 提供账号隔离的详情，生成中的轻量预览可读取但下载和编辑在完成前禁用；PPTX 与图层文件通过鉴权 API 读取。工作台侧栏、大纲详情页和预览详情页支持删除当前账号的大纲草稿或生成历史；删除生成历史会同步清理本地 PPTX 与图片图层产物，生成中的草稿或历史会阻止删除。

## 设计约定

- 默认语言为 `zh-CN`，可在登录后的“体验设置 > 通用”中切换 `en-US`。
- 用户可见文案统一维护在 `messages/`。
- 默认配色预设为“星图”，并预留矩阵、深空、晨雾；入口位于“体验设置 > 外观”，会作用于整个前端。
- 创作输入页的生成意图由创作内容、`PPT 类型`和可选页数共同驱动，默认 PPT 类型为“商务汇报”；PPT 类型决定场景结构、视觉基调和页面组织方式。可选指定页数位于上传文件行右侧，说明文字放在输入框下方；上传文件按钮只显示图标和“添加文件”，单文件大小限制显示在按钮后方，支持格式放在按钮下方；PPT 类型在桌面端使用 4 列等宽网格。首屏标题、输入区、类型选项和右侧栏采用更大的字号与纵向间距，重置和生成大纲草稿操作位于右侧栏下方并使用整行宽按钮。
- 大纲确认页默认展示只读卡片化大纲，保留封面、目录、章节和内容页的纵向结构；预览/编辑状态、页数和“编辑大纲”入口位于底部操作栏中间，用户可直接生成预览 PPT，也可点击“编辑大纲”后修改标题、摘要、页面文案和统一视觉说明。保存或生成会继续复用同一份大纲草稿。
- PPT 预览页的页面元素编排列表保持紧凑，只显示元素角色名称和层级，不显示位置与尺寸；底部元信息区展示当前页 `layoutType`、候选版式和五维设计质量评分，选中图片、图标等文件类元素时，右侧选中元素面板提供“上传新文件”和“删除”，并保留位置与大小编辑，文本元素继续显示内容与位置编辑。
- 右侧栏的大纲草稿和生成历史卡片提供删除图标；大纲详情页底部操作栏和 PPT 预览详情页顶部操作区也提供删除入口，删除前会使用应用内 shadcn/ui 风格弹窗二次确认，不使用浏览器原生确认框。
- PPT 类型在 AI 生成链路中作为场景结构参考值；每轮 LLM 输出都必须与用户原始选择保持一致，不能由模型改写、翻译或替换。历史 JSON 中残留的 deck-level `style` 字段只做读取兼容，归一化后不会暴露给新前端，也不再作为生成控制项。
- 内置 PPT 类型按使用场景分组，包括商务办公、销售市场、教学培训、研究分析和个人展示；销售市场包含运营方案和增长实验。
- 浅色、深色、跟随系统由本地主题 Provider 管理，入口位于“体验设置 > 外观”。
- 当前生成流程优先调用 OpenAI-compatible 文本模型；未配置 `OPENAI_API_KEY` 时使用本地模拟 fallback。
- 若当前账号配置了启用的默认 LLM 模型，AI 拆页优先使用账号配置；否则回退到 `.env` 中的 OpenAI-compatible 配置。
- AI JSON 生成会先使用结构化输出，再退回 JSON mode；若 DeepSeek 等兼容服务商暂不支持 `json_schema` 类型的 `response_format`，会在重试提示中附带 JSON Schema，并对大纲近似 JSON 做窄口径规范化，再交由 zod 严格校验。
- LLM、图片和向量模型拉取都会按常见模型品牌前缀过滤当前供应商返回结果，例如豆包只展示 `doubao-*`，避免同一兼容接口混入其他模型品牌。
- `/{locale}` 是角色分流入口，创作工作台路径为 `/{locale}/workbench`，管理端路径为 `/{locale}/admin`。
- 用户管理页路径为 `/{locale}/admin/users`，模板库管理路径为 `/{locale}/admin/templates`，模板设计器路径为 `/{locale}/admin/templates/{id}`；普通用户访问管理端路由会被重定向回创作工作台。
- 图片图层第一版使用可插拔 Mock SVG 生成器，后续可替换为真实图片生成服务；轻量预览阶段先用 Mock SVG 占位图保证前几页快速可看，真实图片素材按账号内缓存复用，单张图片生成或下载超时会自动降级为 Mock SVG，生成后写入 `storage/assets` 和项目资产目录；PPTX 第一版静态导出并写入 Web 动效备注/metadata，Web 预览支持动效播放。
