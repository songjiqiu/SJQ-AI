# 国际化

## 默认语言

应用默认语言为 `zh-CN`，英文 `en-US` 作为可选语言。路由使用语言前缀，例如 `/zh-CN` 与 `/en-US`。

登录后，语言切换入口放在“体验设置 > 通用”中，并使用下拉框选择中文或英文；未登录的登录/注册页面仍在顶部保留语言切换，方便用户进入账号流程前选择界面语言。

## 文案资源

用户可见文本维护在：

```text
messages/zh-CN.json
messages/en-US.json
```

新增术语、按钮、错误提示、空状态、Toast、元信息时，需要同时补充中英文资源文件，不应把文案硬编码在业务逻辑中。

## 测试要求

`tests/i18n/messages.test.ts` 会检查中英文资源 key 是否一致。新增文案时若只更新一种语言，测试应失败。
