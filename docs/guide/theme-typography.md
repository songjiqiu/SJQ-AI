# 主题与排版

## 外观模式

浅色、深色、跟随系统由本地主题 Provider 管理。当前默认值为 `system`，具体状态由浏览器本地偏好保存，并通过 `html.dark` 与 `color-scheme` 作用到全应用。登录后的切换入口位于“体验设置 > 外观”；未登录页面仍保留顶部切换入口，方便进入账号流程前调整外观。

## 配色预设

当前已预留四组配色：

- 星图：默认预设，用于首版创作工作台。
- 矩阵：偏结构化与数据感。
- 深空：偏沉浸与高对比。
- 晨雾：偏柔和与温暖。

配色通过 CSS variables 承载，登录后的入口位于“体验设置 > 外观”。选择预设会写入浏览器本地保存，并把 `data-palette` 应用到整个前端根节点。

## 排版 token

全局字体、字号节奏、边框半径、前景色、背景色、强调色等由 `src/app/globals.css` 中的 CSS variables 和 Tailwind token 承载。后续若增加全应用字号、行高、内容密度设置，应优先复用这些变量，并记录本地保存 key。
